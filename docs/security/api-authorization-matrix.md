# API Authorization Matrix

The policy below is generated by path classification in
`app/core/security.py`; every non-health route has the authentication dependency.

| Route family/action | Class | Permission | Allowed roles |
|---|---|---|---|
| `/health`, `/api/v1/health` | public | none | all |
| Catalog reads | authenticated read | `catalog.read` | system/catalog admin, editors, inventory operator, read-only |
| Catalog writes | privileged write | `catalog.write` | system admin, catalog admin |
| Attribute reads | authenticated read | `attributes.read` | system/catalog admin, editors, read-only |
| Attribute writes | privileged write | `attributes.write` | system admin, catalog admin |
| Attribute approve/reject/lock | approval | `attributes.approve` | system admin, catalog admin |
| Attribute seed | admin | `catalog.seed` | system admin, catalog admin |
| Content reads | authenticated read | `content.read` | system admin, content roles, read-only |
| Content writes | privileged write | `content.write` | system admin, content roles |
| Content workflow approval | approval | `content.approve` | system admin, content approver |
| Raw preview | admin | `content.raw_preview` plus feature flag | system admin |
| Prompt/scoring administration | admin | corresponding manage permission | system admin |
| Inventory reads | authenticated read | `inventory.read` | system admin, inventory operator, read-only |
| Inventory writes | privileged write | `inventory.write` | system admin, inventory operator |
| Movements/reservations | adjustment | `inventory.adjust` | system admin, inventory operator |
| Job reads | authenticated read | `execution.read` | system admin, execution operator, read-only |
| Job enqueue | privileged submit | `execution.submit` | system admin, execution operator |
| Job cancel/retry | lifecycle management | `execution.manage` | system admin, execution operator |
| `/api/v1/metrics` | operational administration | `admin.access` | system admin, internal service |

For every protected row: missing/invalid/expired credentials return 401;
authenticated principals without the permission return 403; allowed principals
continue to normal validation/business responses. OpenAPI exposes `BearerAuth`.
