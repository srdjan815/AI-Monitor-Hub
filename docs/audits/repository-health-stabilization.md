- `backend/app/modules/catalog/schemas.py`

the package. The package provides distinct category, product, attribute, and
Attribute Type schemas through `schemas/__init__.py`. The monolithic file
lacked the active Product and Attribute Type surface and was not imported.

Resolution:

- retained `backend/app/modules/catalog/schemas/`;
- removed tracked legacy `backend/app/modules/catalog/schemas.py`;
- retained the public internal import path `app.modules.catalog.schemas`;
- added `test_no_module_package_name_collisions` to
  `backend/tests/test_module_boundaries.py`.

API schema names and payloads were not changed.
